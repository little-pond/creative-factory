# Demo video (Remotion)

`creative-factory-demo.mp4` — a 90s editorial walkthrough of the closed loop (GEO angle → factory →
gate-bites → SCALE AI → benchmark). Built with Remotion; design follows the `typography-formulas`
system (color-block / black-&-white / type-as-image, scale-jump, bleed, ≤3 colors, grain).

Reproduce:
```bash
npm install
npx remotion render src/index.ts CreativeFactoryDemo out/creative-factory-demo.mp4
```
